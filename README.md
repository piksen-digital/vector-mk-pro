## Quick Installation & Launch
To test or execute the workspace locally within a single sandbox runtime, follow these simple terminal configurations:

1. **Extract Core Files:** Unpack your downloaded `.zip` file package into your local workspace directory.
2. **Install Standard Build Dependencies:**
   ```bash
   npm install
   ```
3. **Execute Live Interactivity Environment:** Launch the lightning-fast dev runtime environment:
   ```bash
   npm run dev
   ```
4. **Compile Production Build:** Build optimized, secure assets ready for commercial deployment:
   ```bash
   npm run build
   ```

## Clean Integration Interface Framework
To inject VectorForge Pro capabilities into your own SaaS application dashboard setups, initialize the core modules using this clean setup:

```javascript
import { VectorCoreOptimizer } from './assets/js/core-optimizer.js';

const engine = new VectorCoreOptimizer();
const processPreset = { decimalPrecision: 2 };

// Pass raw structural data directly to process
const report = engine.optimize('<svg>...</svg>', processPreset);
console.log('Clean Minified Code:', report.cleanSVG);
console.log('Optimized Vector Nodes Count:', report.nodeCount);
```
